# Repository Guidance

This repository is currently a blank starting point. Do not assume a framework, package manager, or application behavior until project files or requirements establish them.

## Working In This Repository

- Inspect existing files and follow their conventions before making changes.
- Keep changes focused on the requested behavior; avoid unrelated refactors and dependencies.
- Add or update tests for meaningful behavior changes, using the test framework already present.
- Run the narrowest relevant validation after edits and report any checks that could not be run.
- Preserve user changes and do not commit unless explicitly asked.
